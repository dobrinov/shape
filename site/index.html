Why teams switch to Shape

A project lives in six places: a whiteboard, a roadmap, a ticket board, a wireframe tool, a doc of decisions and a slide deck. They drift apart the day after the kick-off. Shape keeps them on one board, and lets the AI keep it current.

✦

Talk to your board

Paste what you learned and Shape puts every fact where it belongs. Ask “what blocks the launch?” and get the answer drawn, each piece linked back. After a week of comments, one click on Rethink brings the whole board up to date.

▦

Six tools, one board

Mindmaps, kanban, gantt charts that forecast, timelines, wireframes for phone and web, decision records, risk matrices, charts and slides. They sit side by side, with boards inside boards for the details.

⎇

Yours, for good

A board is a short text file. It diffs and merges like code, it works offline in its own window, and it is still readable in ten years. Collaboration is commits and pull requests, so there is nothing new to host.

How it works

  1. 1

    Dump it

    Write, paste or drop in what you have: notes, a list, interview quotes, a screenshot. No structure needed.

  2. 2

    Shape it

    The AI sorts it into the right blocks: findings into a mindmap, dates onto a timeline, work onto the kanban, an outage into a post-mortem. You see each change before you keep it.

  3. 3

    Share it

    Open the board through the eyes of leadership, legal or design. Present it as slides. Or copy it as a prompt and hand it to Claude, ChatGPT or your coding agent to build.

Wireframes and flows, in minutes

Sketch the product before anyone opens a design tool. Pick a phone, a tablet or a browser window, click components in, and draw the flow with an arrow from a button to the screen it opens. It sits on the same board as the plan, the data model and the decisions it depends on.

▭

40 components

Headers, navbars, sidebars and tab bars; fields, selects, toggles and sliders; buttons, lists, tables, cards, tabs, steppers, maps, charts, alerts and more. Select a screen and click them in, or pick one from the full list.

Flows, not just screens

Every button and link is its own element. Drag from one to another screen to draw where it goes; drop it on empty space and the next screen appears beside it. Screen flow starts you with three linked screens.

✎

Write it, or let the AI

A screen is a few lines of text: button submit: Sign in [blue]. Edit it as text, review it in a pull request, or tell the AI “a sign-up flow with Google” and it draws the screens.

Draw the spec. Let the AI build it.

For a complex build, the best prompt is a picture of it. Lay out the system, the screens, the data model and the decisions on a board, then press ⌘⇧C. Shape writes the whole thing up as a clean Markdown spec, with every part, every arrow and every open question, ready to paste into Claude, ChatGPT, Cursor or your coding agent.

  • The whole board, canvases included, or just the part you select
  • Screens come out as their components, data models as tables with keys, flows and dependencies as arrows
  • Prompt mindmaps: branch a task into Context, Constraints, Steps and Acceptance, and copy it as a task spec
  • Open comments become the questions the model should ask, not guess
  • From the terminal: shape prompt plan.shape --target build

One board, every audience

The same board tells the story differently to different people. Nobody keeps a separate copy for the board meeting.

  • Perspectives: Senior management sees decisions, risks and the timeline. Legal sees the records. Design sees the screens and the user journey. Each view is one click away, and the AI tags the board for them.
  • Presentation mode: pick the sections, add speaker notes, and present. The view glides across the board from slide to slide, with no deck to keep in sync.
  • Wireframes: sketch phone and web screens as text and draw the flow with arrows from the buttons.
  • Comments with names on any box or arrow, and a full history to go back to.

AI on the plan you already pay for

No API keys and no new bill. Shape uses the command-line tool of the subscription you are already signed into: Claude Code, Codex or Gemini. Without one, it hands you the prompt to paste into any chat.

  • Add what you know (⌘K): write down details and the AI puts them in the right place, shown as a change you can keep or discard
  • Ask: a question about the board, answered with a small diagram drawn for it, each piece linked back to its source
  • Rethink: acts on the open comments, merges duplicates, updates what changed and keeps every perspective filled
  • Recipes: an outage becomes a post-mortem, a status update becomes a traffic light, a sprint becomes a burndown
  • Draft the slides: tell it who the presentation is for and it picks the order, the titles and the speaker notes
  • Comments → prompts: open threads become a task for your coding agent

Git is the database

A board is one text file. Your team already knows how to share it: commit, branch, open a pull request.

  • Edits rewrite only the lines that changed; your notes and formatting stay
  • See what a branch changed, in green, red and amber
  • Boards merge element by element, so most conflicts never happen
  • Every version is one click away; restore any of them (outside git too)
  • Link boards to each other: link: plans/q3.shape#launch

Plain text you can read

One statement per line. Write it by hand, draw it in the editor, or let an agent change it with a few small edits. A pull request shows exactly what changed.

  • Blocks are written as blocks: kanban, timeline, screen, gantt, adr, mindmap…
  • Comments and the presentation live in the file too
  • Models read short outlines and small edits, never coordinates, so AI calls stay cheap
# docs/launch.shape
kanban sprint: Sprint 12 {
  column todo: To do {
    saved: Saved cards [owner: ana]
  }
  column doing: Doing {
    onepage: One-page checkout [blue]
  }
}

screen pay: Pay [mobile] {
  header: Payment
  card saved: Visa •••• 4242
  button pay-now: Pay £42.00 [blue]
}

timeline launch: Launch {
  2026-10-28: Open beta [important]
  2026-11-26: Launch
}

comment on onepage by mia: Behind a flag?
# in your terminal
$ shape ask docs/launch.shape "split Build into API and UI"

# comments → a task for your coding agent
$ shape prompt docs/launch.shape --target code

# let an agent read a few lines, not the whole board
$ shape query docs/launch.shape kind:kanban near:onepage

shape skills install --global # ~/.claude/skills

Get Shape

Or just try it in your browser first, with nothing to install.

Homebrew macOS · Linux

brew install dobrinov/tap/shape

Later: brew upgrade shape.

Download macOS · Linux · Windows

Grab an archive from the latest release (Apple silicon and Intel, Linux x86_64 and arm64, Windows x86_64), unpack it and put shape on your PATH.

From source

git clone {{REPO_URL}} shape && cd shape
make install

Needs Rust with the wasm32-unknown-unknown target and wasm-pack.

Then run shape: it asks where to save your first board and opens it in its own window. shape install-app makes .shape files open with a double-click.

Questions

Is it free?

Yes. Shape is open source under the MIT licence, with no paid tier.

Do I need an API key?

No. Shape uses the command-line tool of an AI subscription you already have (Claude Code, Codex or Gemini CLI), signed in as you. If you have none, the ✦ button explains how to set one up, and meanwhile shows the prompt to paste into any chat.

Where does my data go?

Nowhere new. A board is a file on your disk, the editor runs on your machine, and AI requests go through your own AI tool. The site's playground runs entirely in your browser.

How does my team work on the same board?

Through git: commit the file, branch, open a pull request. Shape shows what a branch changed, merges boards element by element, and signs comments with your name. Outside git, it keeps versions you can go back to.

Can I use it to write prompts for an LLM?

Yes, that is one of the best uses. Draw what you want built (the parts, the screens, the data, the rules), then copy the whole board or a selection as a prompt (⌘⇧C). It is plain Markdown, so it works with any model or coding agent, and the board stays the source you refine between attempts.

Does it replace Jira, Miro or PowerPoint?

For the thinking, planning and explaining part of a project, often yes: it is one board instead of several. It does not try to be a ticket tracker with workflows and permissions.

I used diagram before. Does anything break?

No. Shape was called diagram until October 2026. The diagram command still works as an alias, .diagram files open, merge and link like .shape ones, and with Homebrew, brew migrate diagram once moves you to the shape formula.
